# ポイフォ｜画面仕様

- 作成日: 2026年11月21日（[top-page-spec.md](https://github.com/mizu15963/poifo/blob/87ebcb3/docs/specs/top-page-spec.md) の画面構成を引き継いで作り直し）
- 状態: 実装済みの画面を書き起こしたもの
- 機能のルール（ポイント・換金・イベントなど）: [functional-spec.md](functional-spec.md)。この文書は「どの画面に何を出し、何ができるか」を書く

画面を変えるときは、この文書を直してから実装に反映する。

## 1. 共通

### 1.1 レイアウト

- 主な利用はスマホ。PC もスマホ幅（480px）の画面を中央に置き、画面幅 1024px 以上で左右の余白に左メニュー・右案内を出す。画面の中に PC 専用のレイアウトは作らない
- 色はブランドの2色（濃 `#3AD1CE`、淡 `#86E4E4`）と、キャラクター由来のオレンジを3色目に使う（[../brand/README.md](../brand/README.md)）
- キャラクター（ポイフォックス）は説明系のセクションや案内に使う。案件カードなど API の一覧には入れない
- 見出しは、説明系のセクションは中央揃え、一覧系は左に線を付ける

### 1.2 ヘッダー

- 左にロゴ（トップへ）
- 未ログイン: 「ログイン」
- ログイン中: 「マイページ」
- メニュー: 案件を探す／イベント／担当サポート／ポイント履歴／ポイント交換／ヘルプ

### 1.3 左メニュー・右案内（PC 1024px 以上）

| 場所 | 内容 |
|---|---|
| 左メニュー | コピー「ひとりじゃない、あたらしいポイ活。」、トップ／案件を探す／イベント／担当サポート／はじめての方へ・ヘルプ。ログイン中はマイページ／ポイント履歴／ポイント交換／振込先口座、未ログインはログイン |
| 右案内 | 未ログイン: 「登録無料！LINEですぐ始められます」＋「LINEで無料で始める」。ログイン中: 「今日もポイントを貯めよう」＋「案件を探す」。共通: 担当サポート（公式LINEで相談する）、はじめての方へ |

### 1.4 フッター

サービスについて・ヘルプ／利用規約／プライバシーポリシー／運営者情報／お問い合わせ、© POIFO

### 1.5 スマホの追従ボタン

- スマホで、未ログインのときだけ画面下に「LINEで無料で始める」を追従させる
- ログイン必須のページ・ログイン・認証まわりの画面（検索に出さない画面）には出さない

### 1.6 ログイン必須の画面

- 開いたときにログインを確かめ、確かめ終わるまで本文を出さない
- 未ログインならログイン画面へ移動する

### 1.7 読み込み・エラー

- API から取るところは「読み込み中…」を出してから中身に置き換える
- 取得できないときは「〜を読み込めませんでした。時間をおいて再度お試しください。」、0件のときは「〜はありません」「準備中です」を出す
- ログイン・マイページ・認証まわりは検索エンジンに出さない（noindex）

| 2 | カテゴリから探す | 案件の多いカテゴリ順に、スマホ9件・PC 8件。カテゴリ名と件数。押すと案件一覧をそのカテゴリで開く |

| 6 | ポイフォの特徴 | 自由にポイ活／担当者に相談／みんなで楽しむ |
| 7 | ポイントの貯め方 | 3ステップ |
| 8 | ポイントがもらえるしくみ | あなた・広告主・ポイフォの3者の図 |
| 9 | 貯めたポイントの使い道 | 現金（銀行振込）。交換先は今後追加 |
| 10 | よくある質問 | 開閉式。「ヘルプをもっと見る」→ S15 |

### S02 案件一覧

- 見出し「案件を探す」と、「案件はログインしてから利用してください（ログインしていないとポイントが付きません）」の注意
- カテゴリのタブ（「すべて」が既定）。選ぶと URL に `?category=` を付ける（共有できる）
- 案件カードを20件ずつ。続きは「もっと見る」
- 0件: 「現在掲載中の案件はありません。」

### S03 案件詳細

- 案件名・アイコン・カテゴリ・最大ポイント・掲載終了日
- 獲得条件とポイント: 成果地点ごとに名前・説明・ポイント・判定までの日数
- 成果の条件・注意事項、案件の説明（ASP の文面をそのまま）
- 「ポイントは成果の発生後に『判定中』として表示され、広告主の承認後に利用できるようになります。」
- ボタン: ログイン中「この案件に進む」（API 経由で広告主へ）／未ログイン「LINEでログインして進む」＋「ログインしないとポイントが付きません。」
- 掲載していない案件: 「この案件は現在掲載されていません。」、ない ID: 「案件が見つかりません。」

### S04 イベント一覧

- 見出し「みんなでポイ活！イベント」と説明文
- イベントカードの一覧（並び順 → 開始日時順）。終了したものも残す
- 0件: 「イベントは準備中です。」

### S05 イベント詳細

- タイトル・サムネイル・日時・開催方法・定員（残り◯人）・参加特典（ポイント）・本文・注意事項
- 参加の欄は状況で出し分ける:

| 状況 | 表示 |
|---|---|
| 未ログイン | 「LINEでログインして参加する」 |
| 参加できる | 「このイベントに参加する」＋「参加すると、オープンチャットの参加リンクが表示されます。開始前なら取り消せます。」 |
| 参加予定 | 「参加予定です。当日はオープンチャットで案内します。」「オープンチャットを開く」「参加を取り消す」（確認あり） |
| 満員 | 「満員のため、参加を受け付けていません。」 |
| 開始後 | 「参加の受付は終了しました。」 |
| 終了 | 「このイベントは終了しました。」 |

### S06 ログイン・無料会員登録

- 「ポイフォはLINEアカウントでログインします。初めての方は、そのまま会員登録になります。」
- 「メールアドレスやパスワードの登録はありません。ログイン画面で公式LINEの友だち追加も案内されますが、追加は任意です。」
- 「LINEでログイン」ボタン → LINE の同意画面

### S07 ログイン完了／会員登録完了

- 初めて（`?new=1`）: 「会員登録が完了しました」「ポイフォへようこそ！」、公式LINE の案内と「ポイフォ公式LINEを追加」（任意）、「ポイントを貯める」「マイページへ」
- 2回目以降: 「ログインしました」

### S08 ログインエラー

理由ごとに文言を出す。

| 理由 | 表示 |
|---|---|
| キャンセル | LINEでのログインがキャンセルされました。 |
| 期限切れ | ログインの有効期限が切れました。もう一度お試しください。 |
| 通信失敗 | LINEとの通信に失敗しました。時間をおいてもう一度お試しください。 |
| 退会済み | このLINEアカウントは退会済みのため、ご利用いただけません。お心当たりがない場合はお問い合わせください。 |
| 停止中 | このアカウントは利用を停止しています。詳しくはお問い合わせください。 |

### S09 マイページ

- 「◯◯ さん」
- 利用可能ポイント・判定中ポイント、「判定中のポイントは、広告主の承認後に利用可能になります。」
- メニュー: ポイント履歴／ポイント交換（銀行振込）／振込先口座の登録・変更／公式LINEで担当スタッフに相談する／ログアウト
- 下に小さく「退会する」

### S10 ポイント履歴

- 新しい順に、日時・内容（案件名、換金、イベント参加: <タイトル>、運営による調整（理由）など）・ポイント（＋／−）・状態（判定中／確定／否認）
- 20件ずつ。状態は色だけでなく文字でも出す

### S11 振込先口座の登録

- 入力: 氏名（漢字）／金融機関名／金融機関コード（4桁）／支店名／支店コード（3桁）／口座種別（普通・当座・貯蓄）／口座番号（7桁以内）／口座名義（カタカナ）
- 登録済みなら現在の口座を出す（口座番号は末尾3桁以外伏せる）。変更もこの画面
- 入力の誤りは項目ごとにエラーを出す。ほかの会員が登録済みの口座はエラー
- 登録後はポイント交換（S12）へ戻り「振込先口座を登録しました。」

### S12 ポイント交換（銀行振込）

- 口座が未登録: 「換金するには、先に振込先口座を登録してください。」＋「振込先口座を登録する」
- 登録済み: 利用可能ポイント、最低交換ポイント、交換するポイントの入力欄、申請ボタン、「振込先口座を確認・変更する」
- 注意: 「振込は月に1回まとめて行います。申請から振込まで、審査のため日数がかかります。」「申請したポイントは、申請の時点で残高から差し引かれます。審査の結果お振込みできない場合は、ポイントをお戻しします。」
- 申請履歴: 申請日・ポイント・状態（審査中／振込準備中／振込済み／お振込みできませんでした（ポイント返却済み））

#### 交換先が増えたとき（[機能仕様 7章](functional-spec.md#7-ポイント交換換金)。未実装）

- `/mypage/withdraw/` は「ポイント交換」の入口のまま使う（URL は変えない）
  - 交換先が1つ（今）: 上のとおり、銀行振込の申請画面をそのまま出す
  - 交換先が2つ以上: 利用可能ポイントと交換先の一覧（表示名・アイコン・最低ポイント・交換レート・手数料・受付停止の表示）を出し、選ぶと各交換先の申請画面へ。銀行振込の申請画面は今の内容のまま
- 申請履歴は全交換先をまとめて新しい順に出し、各行に交換先の表示名を付ける。状態の言葉は交換先ごと（銀行振込は今のまま）
- 受け取り情報が要る交換先は、銀行振込の口座（S11）と同じように、その交換先専用の登録画面を足す
- マイページ・メニューの「ポイント交換（銀行振込）」は、交換先が2つ以上になったら「ポイント交換」に変える

### S13 退会

- 「退会する前に必ずご確認ください。」と注意事項
  - 残っているポイント（利用可能・判定中とも）はすべて失効し、元に戻せません
  - 退会後は、同じ LINE アカウントでもう一度登録することはできません
  - 手続き中のポイント交換（申請中・振込待ち）があるときは退会できません
  - 参加予定のイベントがあっても参加特典は受け取れません
- 「上記を確認し、同意します」にチェック → 「退会する」→ 確認（「本当に退会しますか？この操作は取り消せません。」）
- 退会後はログアウトしてトップへ

### S14 担当サポート

- 「困ったときは、担当スタッフに相談。」と説明（初回面談の日程調整も LINE で行う）
- 「公式LINEで相談する」。公式LINE の URL が未設定なら「公式LINEは準備中です。」

### S15 はじめての方へ・ヘルプ

ポイントの貯め方／ポイントの獲得条件・反映について／ポイントの交換方法／担当サポートの利用方法／イベントへの参加方法

### S16 規約など

いまは「準備中です（公開前に運営・法務で内容を確定します）。」

## 5. 画面遷移

```text
トップ
├─ カテゴリ／おすすめ案件 → 案件一覧 → 案件詳細 → （ログイン）→ 広告主のページ
├─ イベント → イベント一覧 → イベント詳細 → （ログイン）→ 参加 → オープンチャット
├─ 担当サポート → 公式LINE
├─ ログイン → LINE → ログイン完了／会員登録完了（→ 公式LINE 追加）
│                 └→ ログインエラー
├─ マイページ ─┬─ ポイント履歴
│              ├─ ポイント交換 ─ 振込先口座の登録
│              └─ 退会
└─ はじめての方へ・ヘルプ
```
